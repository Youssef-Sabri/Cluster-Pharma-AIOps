# ClusterOps — AIOps for Pharmaceutical Procurement & Demand Forecasting

> **Production-Grade AIOps & Procurement Intelligence Platform** for pharmaceutical supply chains, featuring automated multi-horizon demand forecasting, bilingual order matching, real-time drift detection, and automated model governance.
>
> ⚠️ **Synthetic Demonstration Data**: All order histories, pharmacy profiles, and transactions are synthetic, generated by an in-process pharmaceutical market simulator (`app.pipelines.data_generator`). Trade names (Panadol, Augmentin, Brufen, Congestal, etc.) and regional governorates are used solely for realistic bilingual matching and seasonal modeling. No proprietary customer data or private systems are used or claimed.

---

## 1. Executive Summary & Capabilities

ClusterOps operationalizes machine learning in pharmaceutical supply chains across three core pillars:

1. **Demand Forecasting (Intelligence Hub)**:
   - LightGBM Regressors with 10th and 90th quantile uncertainty intervals.
   - Evaluated chronologically against a naive baseline (*same day last week*), achieving a **> 15% reduction in MAE**.
   - Generates automated stock reorder recommendations and procurement forecasts in EGP.
2. **Bilingual Order Matching (*Clara*-Style)**:
   - Two-stage NLP matching engine: rapid in-memory fuzzy matching (`rapidfuzz` `< 1ms`), with Gemini 2.0 Flash LLM re-ranking for ambiguous tokens.
   - Handles Egyptian pharmaceutical vernacular: brand names, active ingredients, Arabic script, Franco-Arabic transliterations, and typing errors.
   - Human-in-the-loop safety: matches under confidence threshold `< 0.50` automatically route to a pharmacist verification queue.
3. **AIOps Governance & Automated Retraining**:
   - Continuous statistical drift monitoring via **Population Stability Index (PSI)** with epsilon smoothing.
   - Automated retraining DAG orchestrated with **Prefect**.
   - **Strict 3% Promotion Gate**: Challenger models replace production champions in the MLflow Model Registry only if out-of-sample MAE improves by at least 3% (`challenger_mae < production_mae * 0.97`).

## 3. Technology Stack

| Layer | Technologies | Role / Justification |
|---|---|---|
| **Frontend** | React 18, Vite 5, TypeScript, Recharts, Vanilla CSS | Polished B2B SaaS dashboard following the Cluster light theme (`clusterapp.net`). |
| **Backend API** | FastAPI, Pydantic v2, Uvicorn, asyncpg | High-performance asynchronous REST API with auto-generated Swagger UI (`/docs`). |
| **Machine Learning** | LightGBM, scikit-learn, numpy, pandas | Quantile demand forecasting and time-series feature engineering without training-serving skew. |
| **NLP & Matching** | rapidfuzz, Gemini 2.0 Flash API | Sub-millisecond fuzzy token matching with LLM fallback for messy bilingual text. |
| **Model Registry** | MLflow | Model tracking, parameter logging, and automated version governance. |
| **Orchestration** | Prefect 3 | Automated retraining workflows triggered on statistical distribution drift. |
| **Database** | PostgreSQL 15, SQLAlchemy 2, Alembic | Async ORM with versioned schema migrations. |
| **Observability** | Prometheus, Grafana | Custom metrics (`p95 latency`, `PSI`, `forecast_mae`, `confidence_bucket`) and pre-provisioned dashboards. |
| **Packaging** | Docker, Docker Compose, Nginx Alpine | Lean multi-container deployment with healthchecks and reverse proxying. |

## 4. Quickstart

### Prerequisites
- Docker & Docker Compose
- Node.js 20+ (for local frontend dev)
- Python 3.11+ (for local backend scripts)

### Run the Full Stack via Docker
```bash
# 1. Clone repository and start all 6 services
docker compose up -d

# 2. Verify all services are healthy
docker compose ps
```

### Access Services
| Interface | URL | Purpose | Credentials |
|---|---|---|---|
| **ClusterOps Frontend** | [http://localhost:3000](http://localhost:3000) | Business workflow & admin console | None |
| **FastAPI Swagger UI** | [http://localhost:8000/docs](http://localhost:8000/docs) | Interactive API exploration | None |
| **MLflow Server** | [http://localhost:5000](http://localhost:5000) | Model registry & run tracking | None |
| **Grafana Dashboards** | [http://localhost:3001](http://localhost:3001) | Real-time observability dashboard | `admin` / `cluster` |

## 6. API Reference

All REST endpoints live under `/api/v1/` and comply with RFC 7807 problem details:

| Method | Endpoint | Description |
|---|---|---|
| `GET` | `/health` | Service uptime, database connectivity, and model load status. |
| `GET` | `/metrics` | Prometheus metrics exposition scraped every 15 seconds. |
| `POST` | `/api/v1/forecast` | Next 7-day demand predictions with 10th/90th quantile intervals. |
| `POST` | `/api/v1/match-order` | Two-stage parsing of raw Egyptian pharmacy text into catalogue SKUs. |
| `GET` | `/api/v1/orders/review-queue` | List low-confidence matches flagged for human pharmacist review. |
| `PATCH`| `/api/v1/orders/review-queue/{id}` | Approve, correct, or dismiss a flagged order match. |
| `GET` | `/api/v1/drift-status` | Latest PSI scores across order volume, basket size, and confidence. |
| `POST` | `/api/v1/retrain` | Trigger Prefect retraining flow and evaluate 3% promotion gate. |
| `GET` | `/api/v1/model-registry` | Active production champion and candidate model versions from MLflow. |
